# ATM Simulation System

## Overview

ATM Simulation System is a Python-based console application that simulates the basic functionality of an Automated Teller Machine (ATM). The project allows users to perform banking operations such as depositing money, withdrawing money, checking account balance, and viewing transaction history.

This project was developed as part of the Machine Learning & Data Science Internship Program.

---

## Features

* Deposit Money
* Withdraw Money
* Balance Inquiry
* Transaction History
* Exception Handling for Invalid Inputs
* Menu-Driven Interface

---

## Technologies Used

* Python 3.x
* Visual Studio Code
* Git & GitHub

## How to Run

1. Clone the repository:

```bash
git clone <repository-link>
```

2. Navigate to the project folder:

```bash
cd ATM-Simulation
```

3. Run the program:

```bash
python atm_simulation.py
```
